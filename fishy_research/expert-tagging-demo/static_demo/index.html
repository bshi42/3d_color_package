How to use this demo

  1. Explore & create your labels first. ↻ Re-roll the batch a few times and study the specimens — note the recurring visual traits (colors, patterns, shapes). For each trait you want to track, type a name in the Tags panel and click + Add. Don't apply anything to specimens yet — just build up your set of labels.
  2. Label a batch. Once you're happy with your set of labels, click a label to make it the active class, then click every specimen that has that trait. Select the next label and repeat, and so on. A single specimen can carry multiple labels. When you've applied all the relevant labels, hit Apply labels → to train the classifier and update the map.
  • If you're not happy with the specimens shown, just ↻ Re-roll for a new batch.
  • You can ⬇ Save / ⬆ Load your labels to a file at any time.
  • You can change how the 2-D graph is colored using the color by dropdown.
