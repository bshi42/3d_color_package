Mark similar / dissimilar vs the anchor
Click a specimen to mark it similar (pull closer); click again to flip to dissimilar (push apart); again to clear. On a marked card, scroll or drag its slider to set how strongly (0–1). Marking similar only pulls — nothing is pushed unless you say so. Ctrl-click a node in the graph — or a leaf/branch in the dendrogram — to add/remove it from this set; a plain click sets the anchor.

How it works
Every specimen is a node; springs link each to its nearest neighbours in the combined color + pattern space, so the layout is a live similarity graph. Drag any node and the rest react. Marking an anchor's neighbours similar → pulled closer or dissimilar → pushed apart adjusts the springs and the graph re-settles globally. The dendrogram clusters the current on-screen layout.
